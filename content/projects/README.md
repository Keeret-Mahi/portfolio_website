# Project writeups

Edit these Markdown files to update the long project case-study pages:

- `goose-calendar.md`
- `cnc-plotter.md`
- `untitled.md`

Use `## Section title` for each section.

Normal paragraphs become case-study text.

Bullets work like this:

```md
- First point
- Second point
```

Media placeholders work like this:

```md
[IMAGE: Screenshot of the upload screen]
[VIDEO: Demo walkthrough]
[DIAGRAM: Parsing pipeline architecture]
```

Tech-stack rows work like this:

```md
**Frontend:** React, TypeScript, Vite
**Styling:** Tailwind CSS
```

After editing, refresh the local site. The page loads these files from `/content/projects/`.
